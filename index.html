    1. 개요

    컴포넌트(소스 폴더)별 코드 규모를 cloc 으로 측정하고, 결과를 서버의 history/ 폴더에 JSON 으로 남기는 사내용 웹입니다. XAMPP(Apache + PHP)만으로 동작하며 데이터베이스와 외부 인터넷 연결이 필요 없습니다.

    탭하는 일
    LOC 조회저장된 이력을 컴포넌트 또는 컴포넌트 그룹 단위로 골라 봅니다 (읽기 전용, 페이지를 열면 보이는 기본 탭).
    LOC 측정폴더나 압축 파일을 골라 측정하고 결과를 이력으로 저장합니다.
    측정 이력저장된 이력 목록. 여러 건 함께 보기, 측정 추이, 전체 Excel 내보내기.
    관리제외 규칙 관리, 저장 이력 관리(버전 수정·삭제), 이 가이드. 비밀번호가 필요합니다.

    2. 설치와 배치

    1. XAMPP for Windows(PHP 8.x 포함)를 설치합니다. 기본 위치는 C:\xampp 입니다.
    2. 프로젝트 폴더를 C:\xampp\htdocs\ 아래(예: C:\xampp\htdocs\loc_mgmt)에 복사합니다.
    3. php.ini 를 확인합니다 (아래 3장, 특히 extension=zip).
    4. XAMPP Control Panel 에서 Apache 의 Start 를 누릅니다. php.ini 를 고친 뒤에는 Stop → Start 로 다시 시작해야 반영됩니다.
    5. 브라우저에서 http://<서버주소>/loc_mgmt/ 를 엽니다. 오른쪽 위에 ● 서버 환경 정상 이 보이면 준비가 끝난 것입니다. 문제가 있으면 원인과 해결 방법이 그 자리(‘자세히’)에 표시됩니다.

    외부 CDN·웹 폰트를 쓰지 않으므로 인터넷이 없는 사내망에서도 그대로 동작합니다.

    3. php.ini 설정

    XAMPP Control Panel → Apache 줄의 Config → PHP (php.ini) (보통 C:\xampp\php\php.ini).

    항목권장 값설명
    extension=zip앞의 ; 제거업로드한 zip 을 풀 때 필요합니다. XAMPP 기본값은 꺼져 있습니다.
    upload_max_filesize16M 이상브라우저가 8MB 조각으로 나눠 보냅니다.
    post_max_size16M 이상upload_max_filesize 이상이어야 합니다.
    max_execution_time600 또는 그대로측정 중에는 set_time_limit 으로 늘립니다. 그 함수가 막혀 있으면 600 이상으로.
    memory_limit256M 이상
    disable_functionsproc_open 이 없어야 함cloc 실행에 proc_open 을 씁니다.

    시간대는 php.ini 의 date.timezone 과 관계없이 config.php 의 APP_TIMEZONE(기본 Asia/Seoul)을 씁니다.

    4. 폴더와 권한

    폴더용도권한 (Apache 실행 계정)
    ctool/cloc-<버전>.exe, cloc-<버전>.pl읽기·실행
    history/측정 이력 JSON (_deleted/ = 삭제한 이력)쓰기
    settings/제외 규칙(exclude_rules.json), 관리자 비밀번호 해시(admin_password.json), 로그인 실패 기록쓰기
    work/업로드·압축 해제 임시 폴더 (측정이 끝나면 지움, 남은 것은 24시간 뒤 정리)쓰기
    api/, assets/, lib/서버 API, 화면 파일, 라이브러리읽기
    • XAMPP Control Panel 로 Apache 를 실행하면 로그인한 사용자 계정으로 돌아가 보통 추가 설정이 필요 없습니다.
    • Apache 를 Windows 서비스로 설치했다면 서비스 계정에 history, settings, work 폴더의 수정 권한을 주세요 (폴더 속성 → 보안).
    • history/ work/ ctool/ settings/ tests/ 와 config.php, 실행 파일은 .htaccess 로 웹에서 직접 열 수 없습니다(403). 이 차단이 동작하려면 Apache 설정에 AllowOverride All 이 필요합니다 (XAMPP 기본값).

    5. cloc · lib 파일

    cloc 버전 올리기: ctool/ 에 새 버전의 cloc-<버전>.exe(또는 .pl)를 넣기만 하면 됩니다. 서버는 이름 규칙(cloc-숫자.숫자….exe)에 맞는 파일 중 버전이 가장 높은 것을 쓰고, 실행되지 않으면 그다음 버전으로 대체합니다. 지금 쓰는 버전은 오른쪽 위 환경 표시와 측정 결과의 “실행 방식”에 나옵니다. 예전 파일은 지우지 않아도 됩니다.

    Perl: exe 실행이 실패하고 서버에 Perl 이 있을 때만 .pl 로 대체합니다. Perl 이 PATH 에 없으면 config.php 의 PERL_BIN 에 절대 경로를 적습니다.

    lib/: 차트와 zip 생성을 위해 lib/chart.umd.js(Chart.js 4.x), lib/jszip.min.js(JSZip 3.x)가 있어야 합니다. 차트 파일이 없으면 표만 보이고, JSZip 이 없으면 폴더 선택 측정은 안 되고 압축 파일 측정만 됩니다.

    6. 화면 사용법

    LOC 측정

    1. 폴더 선택 또는 압축 파일 선택(zip, tar, tar.gz)을 누르거나 점선 영역에 끌어다 놓습니다. 전체 크기는 1GB 이하를 권장합니다.
    2. 컴포넌트 구분: 단일 컴포넌트 = 고른 폴더 전체가 컴포넌트 하나, 컴포넌트 그룹 = 바로 아래 폴더 하나가 컴포넌트 하나(바로 아래 파일은 _root).
    3. 컴포넌트 버전(선택, 50자까지)을 적으면 이력에 함께 저장됩니다. 그룹으로 측정하면 모든 컴포넌트에 같은 버전이 붙습니다.
    4. 필요하면 제외 폴더·확장자·파일을 고치고 측정 시작을 누릅니다. 진행률이 표시되고, 업로드 중에는 취소할 수 있습니다.
    5. 결과를 확인한 뒤 history에 저장을 누르면 컴포넌트마다 이력 파일 하나가 저장됩니다.

    결과 화면 (모든 탭 공통)

    • 보기: 언어별 / 하위 폴더별 / 파일 타입별. 기준: 코드 / 주석 / 빈 줄 / 전체.
    • 차트 안쪽 링은 컴포넌트, 바깥 링은 컴포넌트 안의 항목입니다. 컴포넌트가 16개를 넘으면 작은 것은 기타 로 묶습니다(표에는 모두 나옴).
    • Export to Excel 은 지금 보이는 표를 .xlsx 로 내려받습니다.

    LOC 조회

    • 컴포넌트: 컴포넌트 → 버전(높은 버전이 기본) → 회차(최근이 기본)를 고르면 측정 추이와 결과가 나옵니다.
    • 컴포넌트 그룹: 그룹 → 버전(높은 버전이 기본) → 측정을 고르면 그 측정의 컴포넌트를 한 화면에 봅니다. 컴포넌트 이름(표, 범례, 차트 조각)을 누르면 컴포넌트 탭으로 이동합니다. 보기 하위 폴더별 에서는 차트가 그룹 → 컴포넌트 → 하위 폴더 3단계로 그려집니다.
    • 탭을 열 때마다 목록을 새로 읽습니다. 다른 사람이 방금 저장한 이력은 새로고침으로도 불러올 수 있습니다.

    측정 이력

    • 이력을 누르면 결과와 측정 추이(최근 10회 막대·증감 꺾은선, 회차 표)를 봅니다.
    • 체크한 이력을 함께 보기로 한 화면에서 비교하고, 묶음 배지를 누르면 같은 측정의 이력을 한 번에 고릅니다.
    • 위의 Export to Excel 은 저장된 이력 전체를 내려받습니다.

    관리

    • 제외 규칙 관리: 규칙 추가·수정·삭제·사용 끄기, config.php 기본값으로 초기화.
    • 저장 이력 관리: 컴포넌트 버전 수정(이름은 못 바꿈), 이력 삭제(history/_deleted/ 로 옮김).

    7. 제외 규칙

    • 제외 폴더: 폴더 이름(대소문자 무시, * 사용 가능). 예: node_modules, .git.
    • 제외 확장자: 앞의 점 없이(대소문자 무시). 예: min.js, map.
    • 제외 파일: 파일 이름 전체(대소문자 구분, * 사용 가능). 예: package-lock.json, *.generated.cs.
    • 쓸 수 있는 글자는 영문, 숫자, . _ - * 입니다.
    • 관리 탭에서 사용으로 둔 규칙이 LOC 측정 탭의 “제외 규칙 기본값”이 됩니다. 측정 탭에서 그 측정만 고쳐 쓸 수도 있고, 기본값 버튼으로 끄면 제외 없이 모두 측정합니다.
    • 폴더를 고르면 브라우저가 제외 대상을 빼고 올리고, 압축 파일은 서버가 cloc 실행 때 제외합니다.

    8. 측정 이력 파일

    • 파일명: 컴포넌트_YYMMDDN.json (예: compA_2610071.json). N 은 같은 컴포넌트의 그날 측정 횟수이며 서버가 정합니다. 동시에 저장해도 덮어쓰지 않습니다.
    • 내용: 컴포넌트, 버전, 측정 시각, cloc 버전, 제외 규칙, 언어별·하위 폴더별·파일 타입별 줄 수, 측정 묶음 정보. 소스 코드와 파일 경로는 저장하지 않습니다.
    • 백업: history/ 폴더를 통째로 복사하면 됩니다. 다른 서버로 옮길 때도 이 폴더만 옮기면 이력이 그대로 보입니다.
    • 삭제한 이력은 history/_deleted/ 에 남습니다. 되살리려면 파일을 history/ 로 옮기고 원래 파일명으로 바꿉니다(앞의 삭제 시각 부분 제거).
    • 파일 이름에 쓸 수 없는 글자(\ / : * ? " < > |)는 _ 로 바뀝니다. 한글 이름은 그대로 저장됩니다.

    9. 설정값 (config.php)

    프로젝트 루트의 config.php 를 고친 뒤 저장하면 다음 요청부터 바로 적용됩니다 (Apache 재시작 불필요).

    상수기본값설명
    APP_TIMEZONEAsia/Seoul이력 파일명 날짜, 측정 시각의 기준
    ADMIN_DEFAULT_PASSWORDadmin관리자 초기 비밀번호 (settings/admin_password.json 이 없을 때)
    CLOC_TIMEOUT_SEC120컴포넌트 하나의 cloc 제한 시간(초). 넘으면 그 컴포넌트만 실패
    UPLOAD_CHUNK_BYTES8MB업로드 조각 크기 (php.ini 업로드 한도보다 작게)
    UPLOAD_MAX_BYTES2GB업로드 하나의 최대 크기
    EXTRACT_MAX_BYTES / EXTRACT_MAX_FILES2GB / 200,000압축 해제 총 크기·파일 수 상한 (압축 폭탄 방지)
    WORK_RETENTION_SEC24시간정리되지 못한 임시 폴더 보관 시간
    DEFAULT_EXCLUDE_DIRS / _EXTS / _FILESnode_modules 등제외 규칙 초기값 (관리 탭 “config.php 기본값으로 초기화” 때 사용)
    PERL_BINperlPerl 실행 파일 (PATH 에 없으면 절대 경로)

    10. 관리 인증과 접근 제한

    • 관리 탭 초기 비밀번호는 admin 입니다. 설치 후 바로 관리 → 비밀번호 변경에서 바꾸세요 (초기 비밀번호를 쓰는 동안 관리 탭 위에 안내가 나옵니다).
    • 새 비밀번호는 4자 이상, 앞뒤 공백 없이 입력합니다. 서버의 settings/admin_password.json 에 해시로만 저장되며, 확인은 서버가 합니다.
    • 비밀번호를 바꾸면 다른 PC·탭에서 열려 있던 관리 화면은 다시 로그인해야 합니다.
    • 비밀번호를 잊었을 때: 서버에서 settings/admin_password.json 파일을 지우면 초기 비밀번호(admin)로 돌아갑니다.
    • 인증은 열려 있는 이 페이지에서만 유지됩니다. 새로고침·새 탭·브라우저를 다시 열면 다시 입력해야 하며, 관리 잠그기로 바로 잠글 수 있습니다.
    • 비밀번호를 10분 안에 5번 틀리면 그 PC(IP)는 5분 동안 막힙니다.
    • 관리 탭 밖(조회·측정·측정 이력)에는 로그인이 없어 사내망의 누구나 측정하고 저장할 수 있습니다. 접근을 제한하려면 Apache 설정(예: C:\xampp\apache\conf\extra\httpd-xampp.conf 끝)에 IP 제한을 추가하고 Apache 를 다시 시작합니다.
    <Directory "C:/xampp/htdocs/loc_mgmt">
    Require ip 10.0.0.0/8 192.168.0.0/16
</Directory>

    11. 문제 해결

    오른쪽 위에 “서버 환경에 문제가 N건 있습니다”가 보입니다.
    ‘자세히’를 누르면 항목별 원인과 해결 방법이 나옵니다. 흔한 원인은 zip 확장 꺼짐(extension=zip), history·work 쓰기 권한, ctool/ 의 cloc 파일 누락입니다. php.ini 를 고쳤다면 Apache 를 다시 시작하세요.
    업로드 중 “서버가 받을 수 있는 크기를 넘었습니다(413)”.
    php.ini 의 upload_max_filesize, post_max_size 를 16M 이상으로 올리고 Apache 를 다시 시작합니다.
    일부 컴포넌트가 “제한 시간 초과”로 실패합니다.
    컴포넌트를 나눠 측정하거나 config.php 의 CLOC_TIMEOUT_SEC 를 늘립니다. 나머지 컴포넌트 결과는 정상입니다.
    코드로 인식된 파일이 없다고 나옵니다.
    고른 폴더가 맞는지, 제외 규칙이 너무 넓지 않은지 확인하세요. cloc 이 모르는 확장자는 세지 않습니다(결과 아래 “인식하지 못한 파일”에 나옴).
    차트가 안 보이고 안내 문구만 나옵니다.
    lib/chart.umd.js 가 있는지 확인합니다. 표는 차트 없이도 볼 수 있습니다.
    관리 비밀번호를 여러 번 틀려 막혔습니다.
    5분 뒤에 다시 시도하세요. 비밀번호가 기억나지 않으면 서버에서 settings/admin_password.json 을 지워 초기 비밀번호(admin)로 되돌린 뒤 다시 바꾸세요.
    저장한 이력이 조회 탭이나 측정 이력에 보이지 않습니다.
    각 탭의 새로고침을 누르세요. 그래도 없으면 history/ 폴더에 파일이 있는지, 손상된 JSON 이 아닌지 확인합니다(손상된 파일은 목록에서 빠집니다).
    화면을 고쳤는데 예전 모양이 보입니다.
    브라우저에서 Ctrl+F5 로 새로고침합니다.
    오류 원인을 더 자세히 보고 싶습니다.
    Apache 오류 로그 C:\xampp\apache\logs\error.log 와 브라우저 개발자 도구(F12)의 콘솔을 확인합니다.
